# Suno 批量下载助手

一个用于整理和批量下载自己 Suno 歌曲的 Chrome/Edge 扩展。

## 功能

- 批量导入歌曲链接、歌曲 ID、短分享链接或公开歌单链接
- 从当前 Suno 页面收集已经加载的歌曲
- 自动去重，并发数可设为 1–3
- 暂停派发新任务、失败重试、下载状态跟踪
- 关闭后恢复下载清单
- 无需提供 Suno 密码、Cookie 或会话令牌

## 安装

1. 下载或克隆本仓库。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 开启“开发者模式”。
4. 选择“加载已解压的扩展程序”，然后选择本仓库目录。
5. 在浏览器工具栏固定“Suno 批量下载助手”。

详细使用方法、限制和验证范围见[使用说明](./使用说明.md)。

## 工作方式与限制

本项目根据用户提供的第三方插件客户端行为重新实现，仍依赖 `download.ai-suno.com` 返回歌曲信息和临时音频地址。本仓库不包含该服务的服务器端代码，也不能移除服务端的限制。

下载文件默认保存到浏览器下载目录下的 `SunoBatch` 文件夹。项目只保存原服务返回的 M4A，不进行 MP3/WAV 转码。

项目已通过模拟浏览器 API 验证队列去重、完成判定、中断识别、重试、暂停、限流退避和状态恢复。由于开发环境无法连接原解析服务，真实歌曲下载和速度仍需在浏览器中验证。

请只下载自己拥有权利或已获得授权的内容，并遵守 Suno 当前的服务条款。
